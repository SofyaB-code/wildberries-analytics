# 🌍 Wildberries Analytics

Аналитический сервис для Wildberries — показывает реальные данные по остаткам, ценам и товарам, а также строит графики и таблицы.  
Работает на FastAPI + Chart.js, автоматически обновляет данные каждый день через официальный API WB.

---

## ⚙️ Возможности
✅ Получение данных через API Wildberries  
✅ Автоматическое обновление базы раз в сутки  
✅ Таблицы с товарами, ценами и остатками  
✅ Графики остатков и динамики  
✅ Простое подключение и запуск онлайн (Render, Railway, Vercel)
